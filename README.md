# Everyday Oura Sync

Everyday Oura Sync is a private personal application used by its owner to synchronize selected Oura Ring data into a private personal tracking workflow.

The application uses authorized Oura sleep, activity, and readiness data for personal tracking, summaries, and training-readiness guidance. It is not offered to the public and does not provide medical diagnosis or treatment.
